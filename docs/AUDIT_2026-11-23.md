## New findings

### N24 — Low: the page's CSP still allowed inline scripts

`script-src 'self' 'unsafe-inline'`. No injection point was found, but the policy was the
last line of defence and did not hold: if any future bug let markup into the page, an
inline `<script>` or event handler would run with the cashier's session. The comment in
`next.config.ts` recorded why (static prerendering, the pre-paint script).

**Fixed in this audit's PR:** `src/proxy.ts` gives every page response a fresh random
nonce; `script-src 'self' 'nonce-…' 'strict-dynamic'`, no `'unsafe-inline'`, no eval in
production, plus `upgrade-insecure-requests`. Next.js puts the nonce on its own scripts;
`layout.tsx` puts it on the two pre-paint scripts. The page now renders per request (it
was prerendered). API answers, the service worker script and public files keep a static
policy with no inline scripts. Verified in a browser: sign-in, till, payment pop-up,
service worker and an offline reload all work, with no CSP violations.

### N25 — Low: missing cross-origin isolation and a narrow Permissions-Policy

No `Cross-Origin-Opener-Policy` or `Cross-Origin-Resource-Policy`, and the
Permissions-Policy turned off only camera, microphone, location and payment.

**Fixed:** COOP `same-origin`, CORP `same-origin`, `X-Permitted-Cross-Domain-Policies:
none`, and a Permissions-Policy that allows only full screen (the till's button) and turns
off USB, serial, HID, Bluetooth, MIDI, motion sensors, screen capture, wake lock, WebAuthn
and ad-topic APIs.

### N26 — Low: session cookie was SameSite=Lax

Lax sends the cookie on top-level navigations started by another site. No GET has side
effects, so this was not exploitable, but nothing needs it.

**Fixed:** `SameSite=Strict` on sign-in, PIN switch, renewal and sign-out. Bookmarks, the
home-screen icon and typed addresses are same-site, so staff see no difference.

### N27 — Info: CSV export did not neutralise formula-like cells

`csvCell` escaped quotes and commas but not cells starting with `=`, `+`, `-`, `@`, tab or
carriage return (spreadsheet formula injection). Every exported value is system-generated
today, so it was not exploitable.

**Fixed:** `src/lib/csv.ts` prefixes such text cells with an apostrophe; numbers,
negatives included, stay numbers.

### P13 — Low: the legacy-import test can pass without running

`npm run test:legacy-import` exits 0 and prints nothing when port 15433 is already in use
(for example by a local preview database): no "Running importer…", no checks, no success
line. CI starts clean, so CI is not affected today, but a local "pass" can be false.
Recorded as P13 and fixed in its own pull request (#57), which makes the database test
runners fail loudly when PostgreSQL cannot start and has legacy-import pick a free port.
