## New findings

### N16 — Medium (in PR #37's P3 code): `--rollback` could stop half-way

The rest of `deploy-vps.sh` runs git as root, which leaves root-owned files in `.git`
(confirmed: the index is root-owned after a root git command). The new `--rollback` ran
`git reset` as the service user, which cannot rewrite those files. With `set -e`, the
rollback would have stopped after switching the live link but before restarting, leaving
it half done.

**Fixed in PR #37 before merge:** the rollback runs git as root, like the rest of the
script, and a failure there only warns. The automatic switch-back already tolerated it, and
now warns too.

### N17 — Low (in PR #37's P1/P10 docs): overnight backup collides with updates

The overnight backup ran at 03:05, while the P10 guide schedules unattended upgrades at
03:00. Those can restart PostgreSQL in the middle of a dump.

**Fixed in PR #37:** the overnight backup moves to 02:35.

### N18 — Low: the shift-opened log entry had no name; rule 9 let it through

The `shift_opened` activity row set `userId` (falling back to 1) but no `userName`. Rule 9
accepted any row with a `userId`.

**Fixed in PR #37:**

- the row uses `auditActor()`;
- rule 9 now requires the actor's id **and** name, and was shown to fail on a planted row
  with an id but no name;
- two dead `|| 1` fallbacks in goods receiving were removed (the value is always the
  signed-in user).

### N19 — Low (Open): per-person PIN limits raise guessing capacity per branch

N13 made wrong PINs count against the person typing (10 per 15 min), with a branch-wide
backstop of 40. That stops one mistyping cashier from blocking everyone, but it raises the
most guesses possible in one branch:

- before: 40 per hour;
- now: up to 160 per hour, for someone with sessions open under several colleagues' logins.

A 4-digit PIN still takes days to find, and the owner account cannot be reached by PIN
switch (N5). But this is a trade-off.

**Recommendation:** require 6-digit PINs for managers and the owner (whose PINs approve
refunds, removals and cancels), or lower the backstop to 20.
